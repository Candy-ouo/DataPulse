# DataPulse · 布局方案设计

> 以下提供 3 套布局方案，均基于"KPI 顶部横向 + 下方内容区"的框架，仅在内容区排布方式上有所不同。

---

## 方案 A：三栏对称式（当前方案优化版）

```
┌──────────────────────────────────────────────────────────────┐
│  Top KPI Bar (6 items · 全宽)                                │
├────────────┬──────────────────────────┬──────────────────────┤
│  左栏 3/12  │       中栏 6/12          │      右栏 3/12       │
│            │                          │                      │
│  地域排名   │    数据趋势 (Line)        │    品类售卖 (Bar)     │
│  (表格列表)  │                          │                      │
│            │                          │                      │
│  ────────  │  ─────────────────────── │  ─────────────────── │
│            │                          │                      │
│  系统状态   │    品类分布 (Pie)         │    实时监控 (Gauge)   │
│  (4 标签)   │                          │    (环形进度/仪表)    │
└────────────┴──────────────────────────┴──────────────────────┘
```

**特点**：
- 左栏：信息型（排名 + 状态），用户扫读
- 中栏：核心图表（趋势 + 分布），占最大面积
- 右栏：分析型（售卖 + 监控），辅助决策

**适合场景**：通用型数据大屏，信息密度均衡

---

## 方案 B：上图表 + 下指标式

```
┌──────────────────────────────────────────────────────────────┐
│  Top KPI Bar (6 items · 全宽)                                │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│     全宽趋势图 (LineChart · 高度占 40%)                       │
│                                                              │
├────────────────────┬────────────────────┬────────────────────┤
│                    │                    │                    │
│     品类分布       │     品类售卖        │     地域排名        │
│     (PieChart)     │     (BarChart)     │     (RankList)     │
│                    │                    │                    │
├────────────────────┴────────────────────┴────────────────────┤
│                        系统状态栏                             │
└──────────────────────────────────────────────────────────────┘
```

**特点**：
- 趋势图独占一行，充分展示时间序列数据
- 下方三列等宽，适合对比型分析
- 底部通栏系统状态，不占主空间

**适合场景**：时间趋势为核⼼关注点的场景（如运营/销售监控）

---

## 方案 C：左图表 + 右面板式（仪表盘风格）

```
┌──────────────────────────────────────────────────────────────┐
│  Top KPI Bar (6 items · 全宽)                                │
├──────────────────────────┬───────────────────────────────────┤
│                          │                                   │
│       主图表区 8/12       │       右侧面板 4/12               │
│                          │                                   │
│   ┌──────────────────┐   │   ┌──────────────────────────┐   │
│   │   数据趋势(Line)   │   │   │   核心指标对比            │   │
│   │   (60% 高度)      │   │   │   (KPI 卡片放大展示)      │   │
│   └──────────────────┘   │   │                          │   │
│   ┌──────────────────┐   │   ├──────────────────────────┤   │
│   │   品类分布(Pie)    │   │   │   实时监控               │   │
│   │   (40% 高度)      │   │   │   (Gauge/LED 数字)      │   │
│   └──────────────────┘   │   │                          │   │
│                          │   ├──────────────────────────┤   │
│                          │   │   地域排名 (简短)          │   │
└──────────────────────────┴───────────────────────────────────┘
```

**特点**：
- 左侧 2/3 给图表，视觉冲击力强
- 右侧 1/3 聚合信息面板，适合 PPT 展示
- 右侧突出 KPI 数值，便于决策者扫读

**适合场景**：汇报展示 / 领导驾驶舱 / 强调数据结果的场景
